Это приложение Homey подключается к
• официальному API для разработчиков Electrolux Group по адресу https://api.developer.electrolux.one
• и поддерживает устройства Electrolux и AEG

Инструкция по настройке

1. Войдите на https://developer.electrolux.one с той же учётной записью (e-mail и пароль), что и в приложении Electrolux или AEG.
2. На странице Dashboard создайте API-ключ, затем нажмите GET ACCESS TOKEN, чтобы получить access token и refresh token.
3. Откройте настройки приложения Homey и вставьте API-ключ, access token и refresh token. Приложение обновляет токены автоматически, поэтому используйте пару токенов только для Homey и не передавайте её другим приложениям.
4. Добавьте устройство через приложение и выберите нужный тип: Стиральная машина / Очиститель воздуха и т.д.
5. Если ваше устройство недоступно, посетите https://github.com/gslender/com.electrolux-aeg.ocp/issues/new/choose, чтобы запросить его поддержку.

Бесплатный план разработчика Electrolux допускает 5000 вызовов API в день. При большом количестве устройств интервал опроса автоматически увеличивается, чтобы не превысить этот лимит.

Обновление с версии 1.x: вход по e-mail и паролю больше не поддерживается. После обновления откройте настройки приложения и введите данные разработчика - существующие устройства сохранятся.
